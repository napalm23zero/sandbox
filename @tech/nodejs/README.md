# Node.js

JavaScript runtime built on V8, with an event driven, non blocking I/O model.

## Roadmap

- [ ] Event loop and libuv
- [ ] Modules: CommonJS and ES modules
- [ ] Streams and backpressure
- [ ] Async patterns: callbacks, promises, async/await
- [ ] Worker threads
- [ ] HTTP server without a framework
- [ ] Built-in test runner
