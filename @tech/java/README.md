# Java

Statically typed, object oriented language running on the JVM.

## Roadmap

- [ ] Type system, generics and collections
- [ ] Streams and functional interfaces
- [ ] Records, sealed types and pattern matching
- [ ] Concurrency: executors and CompletableFuture
- [ ] Virtual threads
- [ ] JVM internals: memory model, garbage collection, JIT
- [ ] Testing with JUnit 5
